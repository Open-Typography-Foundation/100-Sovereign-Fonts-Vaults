## 🗂️ Vault Structure

Each numbered vault contains fonts for a specific script/language family:

- **Vaults 1–20**: Major world scripts (Latin, Arabic, Devanagari, Bengali, CJK, etc.)
- **Vaults 21–50**: Regional & minority scripts (Southeast Asia, Africa, Americas, etc.)
- **Vaults 51–80**: Classical & historical scripts (Sanskrit, Gothic, Runic, etc.)
- **Vaults 81–100**: Indigenous & rare scripts (Osage, Bamum, Mende Kikakui, etc.)

## 🚀 Quick Install

### Linux / macOS
```bash
curl -fsSL https://raw.githubusercontent.com/GolamRabbii/fonts/main/install.sh | bash
```

### Windows (PowerShell)
```powershell
irm https://raw.githubusercontent.com/GolamRabbii/fonts/main/install.ps1 | iex
```

### Offline Browser
Open `font_browser.html` in any web browser to explore all 177,259 fonts offline.
